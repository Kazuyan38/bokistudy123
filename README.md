# BokiStudy — 簿記2級への道

日商簿記2級合格を目指す、アプリ完結型の学習システムです。
レッスン（インプット）→ チェックポイント → ドリル → 単元テスト → 間隔反復の復習まで、すべてアプリの中で完結します。

**アプリ URL**: https://kazuyan38.github.io/bokistudy123/

## 特徴（学習科学ベース）

- **テスト効果**: 短いレッスンの直後に必ず小テスト。学習時間の約75%がアウトプット
- **間隔反復**: エビングハウスの忘却曲線に基づくSM-2ライト方式。毎日「今日の復習」を最優先で提示
- **完全習得学習**: 単元テスト80%以上で次の単元がアンロック
- **交互練習**: ミックスドリルは複数単元を横断して弱点論点を優先出題
- **内蔵電卓**: 実務電卓を模した12桁電卓（M+/M−/GT対応）をドリル中いつでも利用可能

## 初回セットアップ（GitHub Pages の有効化）

1. GitHub でこのリポジトリを開く → **Settings** → **Pages**
2. 「Build and deployment」の Source を **Deploy from a branch** にする
3. Branch を **main** / フォルダを **/docs** にして **Save**
4. 数分後に上記URLでアプリが開けます（スマホのブラウザでもOK）

## リポジトリ構成

- `docs/` — アプリ本体（GitHub Pages公開ディレクトリ）
- `docs/data/` — カリキュラム・レッスン・問題データ（JSON）
- `docs/dev/validate.html` — コンテンツ検証ページ
- `design/DESIGN.md` — 設計書（スキーマ・基準値の正本）
- `CLAUDE.md` — Claude（AIアシスタント）の運用ルール
- `tools/validate.mjs` — コンテンツ検証スクリプト（`node tools/validate.mjs`）

## 学習データについて

学習履歴・復習カードはブラウザの localStorage にのみ保存されます（このリポジトリには含まれません）。
設定画面から週1回のバックアップ（エクスポート）を推奨します。

## 教材について

レッスン・問題はすべてオリジナルに作成したものです（実在の過去問・市販教材の転載はありません）。
新しい単元の追加は Claude に依頼してください。
